# DECISIONS

Architecture and art-direction decisions, newest first. Each entry: what was decided, why, and what it supersedes. The Notion "afar — MAS Design Brief" is the founding spec; entries here marked **override** take precedence over it.

## 2026-07-31

- **The spoken `line` is STUDIO SPEECH, not poetry** *(PR: voice-and-bios)*. The old contract ("ONE sentence spoken to the other players") invited multi-clause, multi-addressee metaphor chains that read as nonsense in a speech bubble ("Rust, I heard the hollow — I'm not fixing it, I'm filling it; Keep, that chord doesn't stop ringing…"). New contract, in every persona prompt and few-shot: one concrete thought about what the act just did or is about to do, ≤ ~90 characters, plain words a musician uses between takes, at most one addressee, no semicolons, no stacked metaphors. Character lives in WHAT the act chooses (SILT still fills, RUST still cuts, KEEP still returns), not in ornament. `rationale` stays the fuller inner account (a few sentences, first person, plain); the lyrics contract is unchanged. Applies to future runs — logged lines from old runs stay as history.
- **Stage names reach the kernel; acts first-name each other** *(amends "Stage names are display-only" below — ids are still every log/DB key and URL, but the names are no longer web-only)*. Each `Persona` carries `display_name` / `first_name` / an `addresses` map in metadata, and the base prompts introduce the other two acts by stage name with the standing instruction to call them Delta / Roan / Evers — never a player_id. Diagnosis: the kernel never knew the stage names, so the acts addressed each other as "Rust" and "Keep" in world speech bubbles, breaking the naming register ("the acts use first names for each other").
- **Bios move to the Tunz capsule register** *(amends the 3–5-sentence bio entry below; groundedness rule unchanged)*. `generate_bios.mjs` now asks for the capsule bio a streaming service runs under an artist's name — short declarative sentences, present tense, concrete habits and working methods, 3–4 sentences per act, 1–2 per staff — and explicitly bans essay moves and quoting/paraphrasing the Critic (the Critic's verdicts have their own page section). Still grounded ONLY in the record (stances, logged rationales, staff notes; every quoted phrase in the shipped bios was traced back to a logged source), still human-reviewed before fixtures are committed. Regenerated for all seven inhabitants and published to Neon + fixtures.
- **The world gets a free camera: follow ↔ roam.** *(PR: world-ux.)* Dragging or wheel/trackpad-scrolling over the canvas DETACHES the camera from its scripted follow (roam); a mono chip bottom-left of the canvas (log-line register) reads "● FOLLOWING — click to roam" ↔ "○ ROAMING — click to follow" and clicking it toggles. The rules: (1) a new listening event while roaming never yanks the camera — the chip pulses lamp-colour instead; (2) a deliberate click (rail link or sprite) is user intent — the camera flies there and the mode returns to follow; (3) roaming is clamped to the building plus a 96px (6-tile) margin of night void — the clamp is pure math in `web/lib/world/camera.ts`, unit-tested, and the Phaser camera bounds carry the same rect; (4) +/− buttons bottom-right step zoom 2×/3×, nearest-neighbour (the DOM type overlay scales with it). A drag past 4px suppresses the sprite-click navigation that would otherwise fire on pointer-up.
- **The catalogue rail collapses behind a tab on the seam.** `SplitShell` (client) owns the split; the world pane keeps a 20×56px paper tab on its right edge (mono ⟨/⟩) that opens/closes the rail. State persists in localStorage (`afar.rail`, pure store in `web/lib/world/rail.ts`); default open on desktop, CLOSED on mobile; a pre-hydration inline script stamps the stored state on the SSR HTML so returning visitors never see a layout flash. Closed, the rail's box collapses to zero width but stays in the DOM — the fixed player bar each page renders inside it must stay visible.
- **Mobile treatment: world full-bleed, rail as overlay** *(closes the "mobile is OPEN" entry below; supersedes the 280px-strip stacking)*. Under 900px the world fills the viewport (minus the player bar) with the rail closed by default; opening it overlays the full paper panel over the world, and the seam tab (now riding the right edge) stays above the overlay to close it. The pixel world is the show; on a phone the split had left both halves too small to read.
- **The rail is an index, not a page.** `/world`'s right pane drops to mono-label register: one-line explainer under the wordmark, NOW (one line of live world activity, published by the Phaser scene over a tiny `web/lib/world/now.ts` bus — walker/needle-down lines during listening events, the acts' initials while recording), THE ROSTER (accent chip + name + one-word stance), LATEST RELEASE (mini graph cover + title + catalogue number), THE OFFICE (four names). - **The first two staff exist: the Producer (the cut) and the Critic (the name, last) — run retrospectively at set boundaries.** Each staff agent makes exactly the ONE decision only it makes. `ProducerAgent` (kernel/afar/agents/producer.py) selects which single take per act — from ANY round — makes the release, via ensemble's taste harness: a `Discriminator` over three model-backed judges with heterogeneous groundings (intent-fidelity / arc / distinctness), each scoring an act's whole pool in one call. `choose() == -1` is honored as a real outcome: **"no release this set" is logged, never forced.** `CriticAgent` (kernel/afar/agents/critic.py) writes a third-person, verdict-first retrospective per act (mold's Critic voice, adapted; plain-language rule applies) and then — in a SEPARATE model call that sees only the finished cut and its own review, never the session log — names the release and each selected take, drawing on the acts' own logged words. **The Critic's titles supersede the interim line-derived titles** in Neon (tracks rows carry `titledBy: "the Critic"`). `run_staff` (kernel/afar/staff.py; CLI `kernel/scripts/run_staff.py --run <id>`) obeys the boundary rule: it only reads a COMPLETED run's JSONL, appends new `selections`/`reviews` rows, and writes a new content-addressed release record with `provenance.supersedes_release_id` — the reembed correction pattern; `web/scripts/publish_set.mjs` prefers the staff-enriched record. **Deliberate v1 stub: the judges read the LOG (intents, lines, lyrics, rationales, features), not the audio.** Honest audio judging needs an audio-capable judge; until that is designed, the groundings say out loud that they are log-grounded, and no audio-quality claim is made by the panel.

- **Live renders must never be embedded with the mock embedder; corrections to derived rows are append-only.** Release 0002's first run paid for live ElevenLabs audio and then embedded it with MockEmbedder (the silent `--embedder` default), so every audio-space embeddings/features row was placeholder junk (influence ~±0.00002). Two consequences, now law: (1) **the guard** — `kernel/scripts/step_b.py` refuses a live renderer + mock embedder unless `--allow-mock-embedder` is passed; real money on audio gets real ears, and mock ears become an explicit choice. (2) **the correction pattern** — embeddings/features are derived-never-authoritative, so the fix is `kernel/scripts/reembed.py`: APPEND new embeddings rows (`model_id: "mert"`, a `note` naming the superseded model), recompute audio-space features through the same `compute_space_features` path `run_set` uses, append them as new features rows, and write a NEW content-addressed `release-<hash>.json` carrying a `provenance` block (`{audio_reembedded_from, embedder, supersedes_release_id}`). The mock rows and the old record stay in the log as history — rule 3 means even wrong rows are facts about what happened. `web/scripts/publish_set.mjs` now selects the newest release record by mtime, so Neon mirrors the corrected record. Post-correction check on 0002: audio-space influence is real but small (edges ±0.01–0.11, convergence flat ~0.85–0.90) while intent-space convergence climbs −0.01 → 0.25 — consistent with the standing "intent space leads" stance.

The acts' own generated lines/lyrics/rationales are quoted material and are never rewritten. Applies to pages, metadata, component labels, fixtures prose, and the authored release prose seeded to Neon. Under this rule the tagline becomes: **"Three musicians made of software. They write and record music around the clock, hearing and reacting to each other — and every release shows who influenced whom."** *(Supersedes the tagline below and the note that Csikszentmihalyi vocabulary survives in the Producer bio — "the acts incubate; the Producer precipitates" is replaced by a plain equivalent.)*

- **music_v2 reads CHUNK styles; the global style arrays were silently dropped.** Root cause of the flat MERT gate (intra 0.9397 vs inter 0.9388 — audio effectively identical across personas while intent space separated at purity 1.0): `kernel/afar/mapping.py` was ported from a STALE `afar_music` checkout. music_v2's CompositionPlan is chunks-only — `positive_global_styles`/`negative_global_styles` are the music_v1 MusicPrompt schema and are ignored, as are top-level `context_adherence` and `respect_sections_durations`. Every AFAR track so far got only its lyrics: no palette, no BPM, no persona sound. Fix (ported from afar_music commits 9a02e1b + 5bff478): styles + `context_adherence` live ON the chunk; ranked candidates compete for a **7-positive / 4-negative style budget** (BPM, era lead token, lead genre ×2, vocal-pad leads, and the solo combo are guaranteed slots); only leans ≥0.6 ban the opposing pole; influence token count uses `ceil` so a 10% genre still contributes; lyrics are multi-line (≤8 lines, ≤180 chars/line — the API limit is per LINE); the request body carries ONLY `model_id` + `composition_plan`. Pilot after the fix (6 clips, 2/persona): MERT intra 0.9038 vs inter 0.8749 — a real gap where there was none — and per-persona tempo/timbre structure in plain DSP (rust ~99–103 BPM, low centroid; silt 117.5; keep 112.3).

When porting from `afar_music`, `git -C ../ai-music/afar_music pull` first; the oracle files (`mapping.test.ts`, `music.test.ts`) are the parity bar, not memory of them.

- **Naming resolution** (spec §10 open decision, closed): `ensemble` = framework; **AFAR** = this installation, public face afar.band; `afar_music` = the separate product, afar.music; "The Ensemble Effect" = the offline research project, not a repo.
- **Renderer: ElevenLabs `music_v2` first, behind a swappable `Renderer` protocol.** `continue_from` is in the signature but raises on ElevenLabs (never use `conditioning_ref` for continuity — verified to produce near-covers). `MusicPromptError` is never auto-retried; only transient 429 retries once. 2-slot concurrency semaphore (process-local; needs a cluster lease before multi-process Step C).
- **Python/TS mapping parity is oracle-enforced.** `kernel/afar/mapping.py` must pass the oracles ported from `afar_music/lib/generation/mapping.test.ts`. JS `Math.round` ≠ Python `round` (banker's): all rounding goes through `_js_round(x) = floor(x + 0.5)`.
- **Append-only JSONL is authoritative; Neon is a derived mirror.** Every row carries condition, code_sha, seed, renderer_version, prompt_sha. Perceptions log what the agent *saw*. Artifacts are content-addressed and immutable. Embeddings are derived and carry model_id. *(The spec's earlier byte-identical-replay gate is cut — the experiment runs separately — but these provenance invariants survive it.)*
- **The site renders with zero env.** `web/lib/data.ts` falls back to bundled fixtures when `DATABASE_URL` is unset or any query fails. A broken DB degrades the site to fixtures; it never breaks a page.
- **Audio bytes live in Neon `media` (BYTEA), streamed via `/api/media/[id]`.** Not Vercel Blob (inherited decision from afar_music, where the linked Blob store was private). The `blob_url` pointer indirection keeps the byte store swappable.
- **Vercel:** Root Directory = `web`; framework pinned to `nextjs` in `web/vercel.json` (the dashboard preset was "Other", which made Vercel expect a static `public/` dir — first two deploys failed on these two settings).
- **MERT persona-distinctness gate runs at threshold 0.90, purity w.r.t. act identity.** The spec said 0.85, but mold's FMA bench shows 0.85 only separated Folk; clean separation needed ≥0.90. Do not weaken the threshold to pass — a failure is a persona-prompt problem.
- **Intent-space features are versioned.** `intent_vector` (18-dim: era/10 + 7 sonic + 2 vocal + 8 hashed-genre buckets) is pinned as `INTENT_VECTOR_VERSION = "1"`; embeddings rows carry the version so features stay comparable across runs.
- **Personas are defined by aesthetic commitment only** (accumulation / erosion / continuity), never by their relationship to influence — influence behaviour must emerge. *(Spec §2 trap, adopted as law.)*
- **The boundary rule is a single chokepoint.** `build_context()` is the only place condition branches; staff act between sets on the frame; within a set players perceive only players. The world enters through the brief, never the ear.
