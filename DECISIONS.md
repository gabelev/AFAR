- **Measured hearing: in contact rounds the acts are told what the other takes actually SOUNDED like — derived from the audio itself** *(PR: acts-hear; tier 1 of the audio-perception ladder — captioning models are the phase-2 bench, audio continuation the science track)*. Until now a player's ears were entirely textual: the other acts' lines and DNA said what a take was *supposed* to be, and nothing checked the sound. Now each `others[]` entry in a CONTACT perceive context gains a `heard` dict of measured facts about that act's previous-round take: **DSP facts** (librosa, the `listen` extra, import stays lazy — tempo via beat_track, loudness and brightness as quiet/mid/loud / dark/mid/bright TERCILES vs. the set so far, because "quiet" is only meaningful as a comparison, plus duration) and **relational facts from the audio-embedding space** — cosine distance to the listener's own last take, to the maker's own previous take, and the sign of the influence integrand phrased as perception ("moved toward you / away from you"). The relations are computed in `run_set` right after embedding, from the SAME vectors the embeddings rows log that round (`kernel/afar/perception/ear.py`, pure `hear()`; a no-drift test recomputes every logged heard distance from the logged embeddings), so what the acts were told and what `features.py` later claims can never disagree. **Degradation doctrine**: DSP is optional equipment — librosa absent (mock/offline) or unreadable bytes yields None DSP fields and the relations carry the dict; a failed measurement never blocks a round, and the mock path stays deterministic. **The boundary holds**: `heard_by` rides `RoundEntry` as runner residue, but only `build_context` hands each listener their own listener-relative dict, contact conditions only — alone conditions and a player's OWN take (they made it) never carry `heard`; the whitelist tests pin the exact key set. The prompt renders it as a terse `WHAT YOU HEARD` block in studio language ("Roan's last take: about 98 BPM, quiet, dark, 60 seconds. It moved away from yours — closer to their own last one."), stripped from the room's JSON dump (one fact, said once — the logged perceptions row keeps the full dict), and the shared persona contract now says **"Trust your ears over their words"** — the acts can notice when a line and a sound disagree, which is the thesis in one sentence.
- **The seams are live: the brief reaches the players as a direction frame, and drift reaches the decide prompt** *(PR: length-budget-seams; completes the conductor entry's `ProducerAgent.direct` seam and the era-boundary `SelfState` bumps)*. Round-2 exploration found both designed seams DEAD: the Producer's direction was logged prose that never reached a player's prompt (`conductor.py` logged `_direct()`'s result and dropped it), and `SelfState` drift was logged as `persona_state` rows but never injected anywhere. Both now function. **Brief → players**: `run_set(direction=...)` carries the direction into `build_context`, which adds a `direction` frame dict to EVERY round's context of EVERY condition — isolation included, because the direction is FRAME, not peer material (isolation hears no other player; every act still plays the same session). The frame passes a hard WHITELIST (`direction_frame` in `kernel/afar/perception/context.py`): only `text` / `palette_notes` / `forbidden_moves` / `duration_s` cross — stance, theme, reviews, anything else staff-shaped is structurally unable to enter a mid-set context. `Player._decision_prompt` renders it as "THE PRODUCER'S DIRECTION FOR THIS SESSION" above the room, and the logged perceptions rows carry it verbatim (what the agent saw, exactly). **Drift → prompts**: when residue/obsessions exist, the decide prompt gains one line — "WHERE YOU ARE NOW: Era N, stance S. You keep returning to: …" — built from the player's own `SelfState`, never from context. At era boundaries the conductor seeds each act's obsessions from the top-3 recurring `lyricalObsessions` tags of the act's OWN closing-era intents (`top_obsessions`, pure + tested; read back from the runs' logs — the log is the memory), so drift is grown from what the act actually kept singing about, not authored. `persona_state` rows log the seeded obsessions unchanged — drift is behavioral now, still fully auditable.
- **Song length is the Producer's decision: 30–120s, chosen per session as part of direction** *(same PR; supersedes the hardcoded 30s `TRACK_DURATION_MS` as the only length)*. `ProducerAgent.direct()` makes one model call at set start — prompted with the cost intuition (sketch sessions run short, a session that smells like a single earns 90–120s) and the day's remaining audio-minutes — and the chosen `duration_s` (clamped 30–120; degrades to 30 if the call never parses: the direction always ships) rides the direction frame into `run_set`, every player, and the renderer. `build_composition_plan(intent, lyrics, duration_ms=30_000)`: at ≤45s the plan stays ONE chunk, byte-identical to the pre-variable plan at the 30s default (the oracle-parity bar — the afar_music mapping oracles run untouched); longer takes split into 2–4 sections (2 to 60s, 3 to 90s, 4 beyond; snapshot-tested at 60/90/120s), each chunk carrying the same 7/4-budget style arrays and its contiguous share of the lyric. The lyric line budget derives from duration (~8 lines per 30s, capped at 24; ≤180 chars/line unchanged) and the persona contract now says so — the "one thirty-second track" fiction is gone, replaced by duration-neutral phrasing plus scale-with-the-take lyrics guidance. Renderer seam: `render(..., duration_s=30)` everywhere; the ElevenLabs timeout scales `max(90, 3×duration_s)`; the mock's bytes scale with duration (byte-identical at 30s). `durationSec` on published tracks follows the record's `set.duration_s` (old records read as 30).
- **The budget is MINUTES: `AFAR_DAILY_AUDIO_MINUTES` (default 110/day — the $500/mo sizing) replaces `AFAR_DAILY_GEN_CAP` as the gate** *(same PR; supersedes the conductor entry's 60-generation cap)*. With take lengths variable, generation counts stop measuring cost — minutes of generated audio are what ElevenLabs bills, so minutes are what the conductor caps: at ~$0.15/generated-minute, $500/mo ≈ 110 min/day, and variable lengths self-balance under the one gate (a day of 120s singles simply holds fewer takes than a day of 30s sketches). This also dissolves the exploration-found tension where the 60-generation cap sat under the schedule's own 76-generation/day projection. `GenBudget` meters minutes (float) with the generation count kept as telemetry; `would_exceed` projects `rounds × players × duration_s/60`; the pre-set gate asks whether even the cheapest (30s) version of the set fits, then `_direct` clamps the Producer's chosen duration so the WHOLE set fits the day's remainder (`fit_duration_s`). The state file (`runs/conductor/gen_budget.json`) migrates in place: an old `{day, generations}` file keeps its count as telemetry and estimates minutes at 0.5/generation — every pre-migration take was 30s — so a mid-day deploy neither resets nor double-counts spend. Heartbeat/cap/set rows now log `minutes_today` + `generations_today`; ops env example updated (the droplet env flips at deploy).
- **The world defaults to NOW; the catalogue loop becomes REPLAY** *(PR: world-now-replay; amends the world-catalogue-loop and world-live-poll entries — the loop and the splice are unchanged, they just stop being the default)*. On load the world is in **NOW mode, idle**: the acts potter in their studios — randomized small movements every few seconds (a shift at the console, a turn toward the shelf, a step in place, all existing sprite frames) that claim nothing; speech only ever comes from logged lines, so idle shows each act's LAST logged line dimmed to 45%, the register the design already uses for away-lines. The latest release sits "on the shelf": a turntable bubble reads `LAST RECORD: <TITLE> — AFAR-NNNN · click to play`, the caption reads `LAST RECORD: <TITLE> · THE ACTS ARE IN THE STUDIO`, and clicking the turntable (or the rail's play control) plays that block's staging ONCE — normal follow-camera behaviour — then the world settles back to idle. **Idle never moves the camera.** When the existing live poll splices in a new release, the built arrival staging runs ("A NEW RECORD JUST LANDED", the camera's acknowledging beat), the new block plays once, and idle resumes with the new record as latest — **deliberate simplification: there is no mid-session streaming; the splice arrival IS the live moment.** A rail toggle (NOW / REPLAY, the follow/roam chip's mono register, set on paper) switches to **REPLAY** — the chronological catalogue loop exactly as before — plus a compact release picker (catalogue number + title per block, from the timeline payload) that jumps the loop to a chosen block's start. Mode and picker state deliberately do not persist: every load opens on NOW. The pure state is `web/lib/world/mode.ts` (phase machine idle/once/replay, once-through orders — transition beats stay out of once-throughs, the captions do the announcing — picker→event-index resolution, the idle register lines), unit-tested; rail ↔ world talk over a control bus (`web/lib/world/control.ts`, the fly/now bus shape), so the picker always lists exactly the catalogue the world is playing, spliced arrivals included. `/api/timeline` is untouched — its block order is already chronological (oldest first), so "the latest record" is simply the last block.
- **Staff failures degrade, never void: the material always outranks the commentary** *(PR: staff-degrade; amends the conductor entry's per-set durability and the staff entries' hard-raise parse contracts)*. The first autonomous set (run `20260731-175857-set-0001-contact`) played all 10 rounds — 30 paid generations, a full interaction record — and was then voided as `set_failed` because ONE judge model call at the frame returned an empty reply (`LogJudge.score_pool` → `_loads_lenient`: "Expecting value … (char 0)"). That inversion — commentary failure destroying material — is now impossible, by two mechanisms. **(1) The staff retry ladder** (`kernel/afar/agents/robust.py`, `staff_complete`): every staff-side parse of a model reply — the Producer's judges and note, the Critic's review and naming, the Muse's brief, the Listener's reaction — gets one immediate re-request on an empty/whitespace reply, then one re-prompt carrying the parse error and a "reply with ONLY the JSON" nudge (the `player.decide` idiom), then raises; retries print `staff_retry:` notes (the `render_retry:` journal idiom). **(2) The degradation doctrine** (`run_staff`/`run_muse_listener` in `kernel/afar/staff.py`): each staff stage is wrapped INDIVIDUALLY; a stage that still fails after the ladder logs a `staff_stage_failed` row in its home table (selections/reviews/briefs/reactions) and the chain CONTINUES with that piece absent — Producer down → the final round's takes stand mechanically (release 0002's v1 behavior) with the honest note "The Producer did not file this time"; Critic down → placeholder title "Untitled Session NNNN" (`titlePlaceholder: true`) and "The Critic did not file this time."; Muse/Listener down → brief/reaction absent with the same register of note. The release record carries a `staff_degraded` block (stage → note + error) and provenance names the degraded stages; the publish path (`kernel/afar/publish.py`) prefers these honest notes over the "was not yet built" placeholders. The set then PUBLISHES. The conductor logs a `staff_degraded` row naming the absent stages; **`set_failed` (and the failure backoff) is reserved for `run_set` itself failing.** Only the Producer's deliberate 'no release' verdict — a panel that actually convened and passed nothing — still withholds a release: that is a decision, not a failure.
- **Transient failures retry; a failed set gets a fast second chance** *(PR: transient-retry; amends the 2026-07-30 renderer entry's "only transient 429 retries once")*. The first autonomous set on the droplet died 9 generations in on a plain ElevenLabs 500 whose body said "You have not been charged" — a retryable failure treated as fatal, followed by a full ~8h pace wait. Two fixes. **Renderer** (`kernel/afar/render/elevenlabs.py`): transient 5xx (500/502/503/504) and network-level errors (URLError, no HTTP status) now retry like weather — up to 2 retries at 30s then 90s, escalating; 429 keeps its existing single 3s retry (rate weather passes fast; a second 429 fails). `MusicPromptError` (bad_prompt/bad_composition_plan) stays NEVER-retried — content, not weather. Every retry is printed (`render_retry: ...`) and noted in the result metadata (`render_retry` key), so provenance shows which takes needed a second ask. The 2-slot semaphore wraps ONLY the in-flight request: backoff sleeps happen with the slot RELEASED, so a render waiting out a 500 never starves the other slot (pinned by a slot-probe test). **Conductor** (`kernel/afar/conductor.py`): after a `set_failed`, the next attempt comes after a failure backoff — `AFAR_FAILURE_BACKOFF_MIN` (default 15) minutes, doubling per consecutive failure (15/30/60/...), capped at the unjittered pace interval; one completed set resets it. The daily generation cap still governs every attempt — failed sets spend real generations and that spend keeps counting. The chosen sleep lands in the heartbeat row (`waiting: failure_backoff`, `sleep_seconds`, `consecutive_failures`; the backoff's first beat is forced so the row always exists), and `set_failed` rows carry `consecutive_failures`. The counter is in-memory only: a restart retrying promptly is the behavior we want anyway.

Common-noun uses (lowercase "silt", "rust", "keep" as verbs/materials — e.g. "under enough silt to hold weight", "keep the hum") are NEVER touched. One shared pure function (`web/lib/normalize-act-names.mjs`: capitalized word-boundary matches only, possessives carried over, curated exception list — empty after human review of every substitution in the corpus) is applied in exactly two places: at compile time in `compile_timeline.mjs` (so recompiles keep it) and one-time to the already-published Neon display rows (releases `rationales` + `metadata.lines`, tracks `line`, and the `timeline_source` row's lines) by the idempotent `web/scripts/normalize_names.mjs`. Future runs won't need this (personas now first-name each other — PR #20); this is a display shim for the pre-fix corpus.
- **The world is self-updating: an open tab picks up new releases with no refresh, ever** *(PR: world-live-poll; extends the world-catalogue-loop entry's "rebuild still needed" note from the client side)*. `createWorld` polls `/api/timeline` every ~75s ±15s jitter (`cache: "no-store"`, so no browser cache in the way; the route header drops to `max-age=60, stale-while-revalidate=300` to match), pauses entirely while the tab is hidden, and refetches immediately on return. Poll failures are silent: the world keeps playing the catalogue it has; if the *initial* fetch failed, the first successful poll starts the show late instead of never.
- **The conductor exists: AFAR runs forever under systemd — shipped with the master switch OFF** *(PR: conductor-ops)*. `kernel/afar/conductor.py` is deliberately thin: it WALKS the schedule's eras and sets — per set: `ProducerAgent.direct` consumes the Muse's newest LOGGED brief at set start (cold start = a plain "opens on silence" note; the log, not memory, is where the brief comes from), `run_set` plays the rounds, the staff chain runs at the boundary (Producer → Critic → Muse → Listener via `run_staff`, the conductor's era-scoped `FieldTabooMemory` riding through), the release is PUBLISHED, then the loop paces itself. The boundary rule holds: `build_context` remains the only perceive path; nothing the conductor touches reaches a player mid-set. **Spend control is hard, three knobs**: `AFAR_ENABLED` (ships `0`; disabled the loop idles and writes a `disabled` heartbeat row hourly — an idle conductor is a healthy conductor), `AFAR_DAILY_GEN_CAP` (default 60 generations/UTC-day, a hard ceiling; the counter persists in `runs/conductor/gen_budget.json` so restarts cannot reset spend; a set only starts when its whole projected spend fits, else the loop sleeps to the next UTC day), `AFAR_SETS_PER_DAY` (default 3.0; post-set sleep with ±20% jitter). **Durability**: per-set try/except logs a `set_failed` row and the loop continues (the schedule is position-stable); on boot the conductor resumes idempotently from the JSONL cursor (highest `set_completed`/`set_failed` set index + 1, in `runs/conductor/conductor.jsonl` — a new `conductor` table in the ledger); SIGTERM finishes the current round (`run_set(after_round=...)` → `SetAborted`), leaves the partial rows as history with NO release record, does not advance the cursor, exits 0 — the set replays whole. Era boundaries roll the taboo and bump every player's `SelfState` (logged as `persona_state` rows, from which drift is rebuilt on boot). The ElevenLabs 2-slot semaphore stays in-process: one conductor process IS the cluster; a second kernel writer still needs the lease DECISIONS already flags. The live-renderer/mock-embedder guard is absolute here (no override flag on an unattended loop). `--smoke` runs one 2-round set through the full chain with publish forced dry, the cursor untouched, and the whole run written to a sibling `runs-smoke/` root — mock rows must never seed the canonical log, because the real Muse reads briefs/reactions across ALL of `runs/`.

## 2026-07-30

- **Monorepo.** Kernel (Python) and web (Next.js) both live in `gabelev/AFAR` (`kernel/` + `web/`). *(Supersedes the spec §7 note that the web layer stays in its own repo.)*
- **License: AGPL-3.0-or-later** (was MIT at repo creation) — matches the `ensemble` framework's deliberate network-clause intent for hosted autonomous services.
- **Naming resolution** (spec §10 open decision, closed): `ensemble` = framework; **AFAR** = this installation, public face afar.band; `afar_music` = the separate product, afar.music; "The Ensemble Effect" = the offline research project, not a repo.
- **Renderer: ElevenLabs `music_v2` first, behind a swappable `Renderer` protocol.** `continue_from` is in the signature but raises on ElevenLabs (never use `conditioning_ref` for continuity — verified to produce near-covers). `MusicPromptError` is never auto-retried; only transient 429 retries once. 2-slot concurrency semaphore (process-local; needs a cluster lease before multi-process Step C).
- **Python/TS mapping parity is oracle-enforced.** `kernel/afar/mapping.py` must pass the oracles ported from `afar_music/lib/generation/mapping.test.ts`. JS `Math.round` ≠ Python `round` (banker's): all rounding goes through `_js_round(x) = floor(x + 0.5)`.
- **Append-only JSONL is authoritative; Neon is a derived mirror.** Every row carries condition, code_sha, seed, renderer_version, prompt_sha. Perceptions log what the agent *saw*. Artifacts are content-addressed and immutable. Embeddings are derived and carry model_id. *(The spec's earlier byte-identical-replay gate is cut — the experiment runs separately — but these provenance invariants survive it.)*
- **The site renders with zero env.** `web/lib/data.ts` falls back to bundled fixtures when `DATABASE_URL` is unset or any query fails. A broken DB degrades the site to fixtures; it never breaks a page.
- **Audio bytes live in Neon `media` (BYTEA), streamed via `/api/media/[id]`.** Not Vercel Blob (inherited decision from afar_music, where the linked Blob store was private). The `blob_url` pointer indirection keeps the byte store swappable.
- **Vercel:** Root Directory = `web`; framework pinned to `nextjs` in `web/vercel.json` (the dashboard preset was "Other", which made Vercel expect a static `public/` dir — first two deploys failed on these two settings).
- **MERT persona-distinctness gate runs at threshold 0.90, purity w.r.t. act identity.** The spec said 0.85, but mold's FMA bench shows 0.85 only separated Folk; clean separation needed ≥0.90. Do not weaken the threshold to pass — a failure is a persona-prompt problem.
- **Intent-space features are versioned.** `intent_vector` (18-dim: era/10 + 7 sonic + 2 vocal + 8 hashed-genre buckets) is pinned as `INTENT_VECTOR_VERSION = "1"`; embeddings rows carry the version so features stay comparable across runs.
- **Personas are defined by aesthetic commitment only** (accumulation / erosion / continuity), never by their relationship to influence — influence behaviour must emerge. *(Spec §2 trap, adopted as law.)*
- **The boundary rule is a single chokepoint.** `build_context()` is the only place condition branches; staff act between sets on the frame; within a set players perceive only players. The world enters through the brief, never the ear.
